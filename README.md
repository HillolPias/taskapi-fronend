Ledger — a task and project manager with a custom-designed UI and a live AI chat interface.

Built with Next.js App Router (Server + Client Components), TypeScript, and Tailwind CSS. Full CRUD for projects and tasks, plus a chat interface that streams responses token-by-token from a tool-calling LangGraph agent — watch it reason, call tools, and answer live, backed by the Ledger API.

Stack: Next.js 15 (App Router) · TypeScript · Tailwind CSS · Server Components
Deployed: Vercel
